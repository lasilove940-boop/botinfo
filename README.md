# Бот менеджер проектов

Это удобный бот, который помогает пользователям создавать новые проекты и организованно хранить их в одном месте. Он может создавать новые проекты, изменять их и удалять старые по вашему желанию.

В скрипте, возле каждой команды указано краткое описание. Так же бот предоставляет в начале описание каждой команды для удобства.
